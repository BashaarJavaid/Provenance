Six surfaces (ARCHITECTURE.md §8.2). The fleet view and the ledger read GET /trace — the same spans exported to Cloud Trace, held in process so they render while the incident is still running. The Executor has no row because it emits no span: what came of it reaches the trace through the verification span that judges it. The belief inspector reads GET /belief/{entity} instead, and has to: §8.1 keeps content off spans, and a belief's evidence and arithmetic are content (docs/adr/ADR-021). The registry panel reads GET /registry for the same reason: standing is stored state, and a counter derived from an in-process buffer can disagree with the registry it claims to show.
